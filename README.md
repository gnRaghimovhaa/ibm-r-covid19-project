# IBM R COVID-19 Data Analysis Project

##  Project Overview

This project was completed as the final assignment for the **IBM Introduction to R Programming for Data Science** course on Coursera.

The objective was to collect, clean, process, and analyze global COVID-19 testing data using the R programming language.

---

##  Project Objectives

* Retrieve COVID-19 data from a web page
* Extract HTML tables
* Clean and preprocess the dataset
* Export the processed data to CSV
* Analyze COVID-19 statistics
* Compare infection ratios between countries
* Filter and sort country data using R

---

##  Technologies Used

* R
* Jupyter Notebook
* httr
* rvest
